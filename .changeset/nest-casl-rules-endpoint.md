`CaslModule.forRulesEndpoint({ path })` serves the Rules endpoint, ready-made and optional: `GET <path>` answers `{ rules }`, the packed rules of the Ability of the user `getUserFromRequest` finds, and 401 to an Unauthenticated request. The browser builds its Client ability from it with `@jperezmart/casl-react`, so you no longer write the "my abilities" controller yourself.
